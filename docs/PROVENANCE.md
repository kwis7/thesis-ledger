# Provenance and reuse boundaries

This code is an original implementation of an accumulated personal research workflow. The shareable methods are company-specific operating bridges, source chronology, explicit uncertainty and falsifiers, common-equity valuation, frozen forecasts, a friendly research workbench, material-event monitoring and durable notification state.

The public project reconstructs these methods with invented fixtures, explicitly attributed public EXE financial excerpts and a portable runtime. It contains no personal cloud endpoints, account integrations, holdings, private research history or credential workflow. No private repository history is imported.

The following public projects informed product questions during design. They are references, not bundled dependencies or copied implementations:

| Reference | Design question |
| --- | --- |
| [TradingAgents](https://github.com/TauricResearch/TradingAgents) | How should analyst workflow, dated inputs and resumable runs be explicit? |
| [AI Hedge Fund](https://github.com/virattt/ai-hedge-fund) | How can a packaged entry and persistent ledger make behavior inspectable? |
| [OpenBB](https://github.com/openbq-org/OpenBB) | How can providers stay behind normalized data contracts? |
| [Qlib](https://github.com/microsoft/qlib) | How can evaluation and pipeline configuration be reproducible? |
| [FinGPT](https://github.com/AI4Finance-Foundation/FinGPT) | Which financial NLP task actually needs a domain-specific evaluation? |
| [Ghostfolio](https://github.com/ghostfolio/ghostfolio) | How can a personal dashboard and history feel usable? |

No performance, star count, current maintenance status or licensing compatibility is inferred from this reference list. The runtime has no external package dependencies; optional packaging uses setuptools. Browser assets are original and contain no remote fonts, scripts or imagery.

The [SEC EDGAR API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) defines the implemented opt-in JSON adapter. The EXE case includes 36 curated public fact records and small attributed response excerpts, not complete filings, an exhaustive SEC dataset or provider prices. Actual source-response hashes and excerpt hashes are distinct. Review a source's data rights and access requirements before adding live collection or public datasets.

[FinQA](https://github.com/czyssrs/FinQA) informed the separation of supporting facts, executable calculations and fixed evaluation labels. Its code and dataset are not bundled.
